# Copy Inline Code 2.1.0

> [!IMPORTANT]
> **Copy Inline Code is active again and now has a new maintainer: @Vitovt — github.com/vitovt.**
>
> The plugin has been substantially rewritten and modernized, with its internal implementation rebuilt to improve reliability, maintainability, and compatibility with current Obsidian versions.
>
> This release also updates security-related dependencies and tooling, fixes existing bugs, improves usability, and introduces new customization options.
>
> If you encounter a bug or have an idea for an improvement, please open an issue. Bug reports and feature requests are welcome, and active maintenance will continue.

This release brings the improvements developed during continued maintenance back to the official **Copy Inline Code** repository.

## User-facing improvements

- Show hover-only copy icons as true overlays, without reserving extra space or affecting line length or line height.
- Keep both Lucide and legacy icons visible and clickable in permanent and hover modes.
- Hide copy icons from **printed documents** and PDF exports.
- Apply setting changes immediately in both Live Preview and Reading Mode without requiring an Obsidian restart.
- Add an **Icon position** setting with **Right** as the default and **Left** as an alternative.
- Apply the selected icon position consistently across permanent and hover modes with both supported icon types.
- Improve overall interaction and visual consistency between Live Preview and Reading Mode.

## Reliability and settings

- Rework the internal implementation to use shared icon creation and clipboard handling across Live Preview and Reading Mode.
- Report clipboard failures correctly instead of showing a successful copy notification when copying fails.
- Validate saved settings before applying them.
- Validate regular-expression filters and safely handle invalid expressions.
- Improve the settings interface with searchable setting definitions on current Obsidian versions while retaining compatibility with older versions.
- Improve internal state handling so configuration changes take effect immediately and consistently.

## Security and maintenance

- Update project dependencies and apply all available non-breaking security fixes.
- Modernize the TypeScript, ESLint, and esbuild configuration.
- Add Obsidian-specific validation and quality checks.
- Add reproducible local build, validation, and release tooling.
- Clean up and restructure the codebase to make future maintenance and development easier.
- Preserve the original **GNU General Public License v3.0**.
