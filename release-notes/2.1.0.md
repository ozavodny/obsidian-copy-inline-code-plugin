# Copy Inline Code 2.1.0

This release brings the improvements developed during continued maintenance back to the official Copy Inline Code repository.

## User-facing improvements

- Show hover-only copy icons as overlays, without reserving extra space or changing line length or line height.
- Keep both Lucide and legacy icons visible and clickable in permanent and hover modes.
- Hide copy icons from printed documents and PDF exports.
- Apply setting changes immediately in Live Preview and Reading Mode without restarting Obsidian.
- Add an **Icon position** setting with **Right** as the default and **Left** as an alternative.
- Apply the selected icon position consistently to permanent and hover modes with both icon types.

## Reliability and settings

- Use shared icon creation and clipboard handling so Live Preview and Reading Mode behave consistently.
- Report clipboard failures instead of showing a successful copy notification when copying fails.
- Validate saved settings and regular-expression filters before using them.
- Improve the settings interface with searchable definitions on current Obsidian versions while retaining compatibility with older versions.

- Add reproducible local build, validation, and release tooling.
